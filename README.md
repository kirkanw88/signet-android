# Signet VPN для Android

Нативный клиент `com.signet.client`: Kotlin, Compose, Android VpnService, официальный libXray/Xray 26.11.9. Версия приложения 0.2.4. Android 8.0 / API 26 и новее.

## Установка

Установите APK из [публичных Releases](https://github.com/kirkanw88/signet-android/releases/latest) или `release/`. Для современных телефонов используйте `signet-0.2.4-arm64-v8a.apk`. В настройках откройте «Подписки» и импортируйте вашу HTTPS-ссылку, QR, файл, VLESS/Hysteria2 URI или Xray JSON. Сервер выбирается нажатием на страну на главном экране. При первом подключении подтвердите системное разрешение Android VPN. Проверка подключения имеет отдельный HTTPS адрес; для измерения задержки URL по умолчанию — `https://www.gstatic.com/generate_204`.

Сборка подписана локальным сертификатом разработки, пригодна для установки, не опубликована в Google Play. Это первая сборка: проверенные сценарии и ограничения перечислены в [отчёте](docs/TEST_REPORT.md). Нельзя считать все пункты исходного ТЗ прошедшими приёмку на основании наличия APK.

## Возможности

- Полный системный TUN с IPv4/IPv6 маршрутами; прямой native TUN Xray, без tun2socks.
- VLESS, REALITY/Vision, XHTTP TLS/REALITY, Hysteria2, SOCKS/HTTP через конфигурации закреплённого ядра. URI разбирает сам libXray; полный JSON сохраняется без проекции полей.
- Несколько подписок; Base64, JSON-объекты/массивы, share links; AGE с предоставленным пользователем ключом. HTTPS, сроки и трафик из subscription-userinfo. Обновление каждые 6 часов через WorkManager.
- Серверы в нижней шторке: страны, номера и «Игровой», локальные флаги, избранное, поиск и сортировка. Signet_White сохранён, Signet_Auto распознаётся как AUTO. Исходный JSON AUTO сохраняется. Android runtime добавляет только внутренний DNS-мост; новые служебные handlers исключаются из AUTO selectors без изменения состава исходных узлов.
- Одна кнопка подключения/отключения, стеклянные поверхности, читаемые настройки и отдельный журнал подключения до 200 строк в памяти. Быстрое вращение Земли при подключении убрано; фототекстуры с облаками и ночными огнями освещаются по текущему UTC.
- Настраиваемые TCP/HTTPS/полный Xray/отдельный outbound пробы в изолированном процессе, ограниченная параллельность и отмена; автоматические пробы только выбранного профиля при открытом приложении.
- «Настройки → Проверить обновление» и баннер нового стабильного выпуска из публичных GitHub Releases. Без GitHub токена; загрузка только по нажатию в окне с прогрессом, потоково в PackageInstaller session без отдельной копии APK в Downloads. Размер/SHA-256 проверяются до системной установки; staged data удаляются при отмене/ошибке и после установки. Репозиторий и стабильные Releases публичны по решению владельца; приложение проверяет обновления без токена.
- Собственный QR-экран с разрешением камеры, фонариком, импортом изображения и подтверждением. Перенос per-app правил через версионированный JSON с предварительным просмотром.

Границы версии: [Release 0.2.0](docs/RELEASE_0_2_0.md), [типовые Remnawave шаблоны](docs/REMNAWAVE_TEMPLATE_COMPATIBILITY.md), [XDrive](docs/XDRIVE_INTEGRATION.md), [MASQUE](docs/MASQUE_INTEGRATION.md), [API](docs/API_CONTRACTS.md). Customer API подготовлен локально и требует отдельного развёртывания: см. [клиент API](docs/MOBILE_API_CLIENT.md). Нативные баланс, устройства, автопродление и поддержка используют общий аккаунт кабинета/бота; платежи остаются в защищённом web checkout.
- Per-app include/exclude, редактор полного Xray-профиля с проверкой ядром и восстановлением оригинала. DNS и routing из подписки сохраняются.
- OpenGL ES сфера, текстура Земли, освещение и ночная сторона, атмосфера, фото облаков, реальные границы Natural Earth. После приближения появляется маркер столицы с английским названием; звёздный фон занимает весь экран.
- Оригинальный логотип преобразован в прозрачные SVG и Android VectorDrawable. Генерированный вариант логотипа не включён.
- AES-GCM / Android Keystore; Room хранит только шифротекст. Никаких административных токенов, аналитики, рекламных SDK или файловых логов трафика.

## Память и накопление данных

Лимит одного загружаемого документа — 4 МБ; максимум 8 подписок, 500 узлов и 8 МБ текста рабочих конфигураций. Сохранённые оригиналы и JSON-экранирование увеличивают зашифрованный объём относительно этого лимита; это не лимит полного размера установки. Удаление подписки освобождает её данные логически; SQLite может оставить выделенные страницы для повторного использования.

HTTP-кеш на диске отсутствует. Пробы не пишутся в БД, старые результаты заменяются. Процесс проб завершается после отвязки. Базовая текстура ограничена 2048 пикселями; из 8K detail JPEG декодируется только регион 2048×2048 RGB565 вокруг столицы, CPU bitmap GL-текстур сразу освобождается. Полноэкранный фон Compose использует один RGB565 bitmap на открытый экран; он освобождается вместе с экраном и не накапливается в коллекции. GL-контекст уничтожается при уходе с экрана; VPN продолжает работать. High / Balanced / Battery Saver ограничивают рендеринг приблизительно 60 / 30 / 10 кадрами в секунду. Это предел частоты, а не обещание достигнутых 60 FPS на любом устройстве.

GeoIP/GeoSite встроены в APK и один раз копируются в приватный каталог для ядра (около 10.7 МБ). Для экономии места устанавливайте один APK вашей архитектуры. Не устанавливайте универсальный APK, если архитектура известна.

## Сборка

JDK 17, Android SDK 36, Gradle 8.13:

```powershell
python scripts/fetch-native.py
.\gradlew.bat :core:test :app:lintDebug :app:assembleRelease
```

`fetch-native.py` проверяет SHA-256 официальных архивов перед извлечением. Ресурсы Земли и бренда уже находятся в исходниках. На Windows со старым JDK и кириллицей в пути используйте ASCII-путь для проекта и GRADLE_USER_HOME; воспроизводимый пример находится в `scripts/build.ps1`.

Для инструментальных тестов нужен эмулятор/телефон. `ClientIntegrationTest` с параметром `localVpn=true` использует только локальные тестовые узлы из `tests/local-vless.json`. Без параметра сетевые интеграционные тесты пропускаются. Статический тестовый REALITY-ключ из этого файла предназначен исключительно для loopback-стенда.
