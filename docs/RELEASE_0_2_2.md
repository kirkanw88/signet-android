# Signet VPN 0.2.2

На главном экране крупная Земля и одна кнопка подключения/отключения. Нижнее меню убрано. Нажатие на выбранную страну открывает анимированную шторку серверов; измерение задержки и обновление подписок находятся в ней и обозначены иконками. Настройки разделены на читаемые карточки: подписки, серверы, аккаунт, соединение, маршрутизация, оформление, обновления, диагностика и журнал.

В названиях показываются страны, порядковые номера и пометка «Игровой». `Signet_White` сохранён. Имя `Signet_Auto` распознаётся как предоставленный сервером AUTO и отображается как «AUTO». Исходные конфигурации, маршруты и идентификаторы не переименовываются. Строка описания строится по профилю, например `VLESS / XHTTP / TLS / JSON`; для URI-подписки последняя часть — `URI`.

При подключении планета плавно поворачивается к стране и приближается. Быстрое вращение убрано. Используются фототекстуры Земли с облаками и ночными огнями NASA. Приближённое положение Солнца рассчитывается по текущему UTC по [формулам NOAA](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF) и обновляется раз в минуту. Ночные огни видны на фактически неосвещённой стороне. Это исторические фототекстуры с текущей моделью освещения; текущая погода не запрашивается. Космический фон создан встроенным imagegen: [ассет, происхождение и точный промпт](../assets/space-source.json).

Исправлен подтверждённый дефект проверки HTTPS: статус 403/451/503 ошибочно считался отсутствием VPN, несмотря на состоявшийся TLS-обмен. Теперь такой ответ подтверждает передачу HTTPS; проверка сертификата сохраняется. Добавлены ограниченные повторы после настройки TUN. Проверка подключения отделена от измерения задержки, URL по умолчанию для измерения — `https://www.gstatic.com/generate_204`. Точная причина отказа конкретной пользовательской подписки пока не воспроизведена: её конфигурация и подробная ошибка не предоставлены. Новая диагностика различает DNS, TLS, таймаут и отсутствие соединения.

Журнал подключения включается в настройках, хранит до 200 строк только в оперативной памяти, поддерживает просмотр, очистку, копирование и экспорт. Записываются коды этапов VPN/HTTPS/проб, без URL подписки, UUID, HWID, ключей и JSON конфигураций. Отключение записи очищает журнал. Постоянные файловые логи Xray не включаются. Растровые текстуры ограничены 2048 пикселями по ширине, временные bitmap освобождаются после передачи в GPU. Стеклянные кнопки не используют blur-буферы.

Репозиторий публичный: [kirkanw88/signet-android](https://github.com/kirkanw88/signet-android). Обновление из установленной 0.2.1 проверяется кнопкой «Проверить обновление». В 0.2.2 она находится в «Настройки → Обновления». APK подписаны прежним локальным development-сертификатом. Производственный ключ не публикуется, main и инфраструктура Signet не изменялись.

Проверки ограничены целевыми JVM-тестами, компиляцией интерфейса и сборкой Release по просьбе пользователя; длительный эмуляторный прогон не повторяется. [Фактические результаты](TEST_REPORT.md).
