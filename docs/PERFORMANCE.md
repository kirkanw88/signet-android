# Память и производительность

Установочный APK разделён по архитектурам; пользователю нужен только один файл. Универсальная сборка существенно больше и не включается в пользовательский комплект. Официальное native ядро занимает основную часть APK; искусственно обещать маленький размер без замены ядра нельзя.

Дисковые ограничения: документ до 4 МБ, до 8 подписок, 500 узлов, 8 МБ текста рабочих конфигураций. Сохранённые оригиналы, шифрование и JSON увеличивают фактический объём БД. GeoIP/GeoSite один раз копируются из APK в приватный каталог, около 10.7 МБ. Это постоянные данные, не растущий журнал.

Нет дискового HTTP-кэша и постоянной истории проб. В release нет файловых логов трафика. Процесс проб прекращается после отвязки. Socket callbacks регистрируются один раз за жизнь процесса и не накапливают старые VPN-сервисы. Загрузка подписки ограничена размером и общим таймаутом.

Текстура Земли ограничена 2048 пикселями, промежуточный Bitmap освобождается. При уходе экрана в фон GL-контекст освобождается, VPN остаётся отдельным foreground service. Режимы качества ограничивают частоту приблизительно 60/30/10 FPS. Достижение 60 FPS, батарея и температура на физическом телефоне: NOT RUN.

Предварительный debug-снимок: PSS 121479 КБ (около 118.6 МиБ), RSS 250192 КБ. Он сделан до последних исправлений и не описывает финальный release. Исходный вывод: `tests/evidence/memory-debug-active.txt`. Измерение final release BLOCKED из-за отказа загрузки эмулятора. PSS включает управляемую/native память и графику; один снимок не доказывает отсутствие утечки. Длительный soak-тест и профилирование heap на телефоне ещё необходимы. Приложение не обещает нулевое потребление памяти во время VPN.
