# Signet VPN 0.2.9 — JSON, описания серверов и светлая тема

Только универсальная редакция `com.signet.client.external`, code 11. Signet с кабинетом остаётся 0.2.6; production, панель и backend не изменяются.

## Подписки

В 0.2.6 при разделении редакций universal перестала явно запрашивать Remnawave `/json`. Вместо полного шаблона могла приходить Base64/URI-выдача: её JSON-only host, например Signet_Auto, нельзя восстановить из отдельных ссылок. Ещё одна ошибка: provider description скрывал строку протокола/формата.

Теперь исходная HTTPS-ссылка запрашивается первой. Полный Xray JSON с описаниями используется сразу. После реального URI-списка выполняется одна дополнительная попытка получить полный JSON по `/json` того же origin. Для панели с уже JSON-ответом без описаний разрешён такой же запрос расширенных метаданных. Внешние статические JSON с готовыми описаниями не требуют второго запроса.

Remnawave передаёт `meta.serverDescription` только расширенным клиентам. Для дополнительного запроса используется capability-совместимость `Happ/compatible SignetVPN/<version> (Android ...)`: префикс соответствует upstream extended-client regex, реальный продукт остаётся в User-Agent, версия Happ не выдумывается. Первичный запрос сохраняет нативный Signet UA. Исходный отказ доступа не запускает обходные запросы. Панель не перенастраивается.

JSON принимается только как полный Xray-профиль с протоколами outbounds и корректными статическими ссылками routing/balancers. Другой JSON (в том числе sing-box) не заменяет рабочий URI-ответ. Неподдерживаемый endpoint, отказ дополнительного запроса, недоступность сети, некорректное тело или редирект на другой origin сохраняют исходную рабочую выдачу. Лимит 4 МиБ, HTTPS, ограничение редиректов, HWID и проверка шаблона сохранены. Для каждого дополнительного HTTP-вызова установлен таймаут 8 секунд. Заголовки трафика, срока и профиля сохраняются, если дополнительный ответ их не повторяет.

Signet_Auto отображается под собственным именем. Его полный JSON, DNS, порядок outbounds, routing и balancers сохраняются; AUTO не синтезируется и не превращается в «первый/самый быстрый сервер». У каждого сервера отдельная строка протокола/формата (`VLESS / XHTTP / TLS / JSON` либо честное `URI`), затем описание `meta.serverDescription`, включая AUTO. Подпись формата не вытесняется длинным описанием.

**После установки обновите подписку кнопкой ↻ в шторке серверов.** Сохранённая URI-выдача без повторного запроса не содержит отсутствующих JSON-профилей и описаний. Ссылку заново добавлять или удалять приложение не нужно.

## Светлая тема

Белый векторный логотип окрашивается в тёмный цвет с сохранением исходной геометрии и прозрачности. Космос в GL-области смешивается со светлым фоном; экспозиция дневной поверхности и фоновая освещённость ночной стороны увеличены. Реальный UTC, граница дня/ночи, огни городов, приближение и границы стран сохранены. Для тёмной темы uniform равен нулю, прежняя формула освещения сохраняется. Новых bitmap, текстур и blur buffers нет.
