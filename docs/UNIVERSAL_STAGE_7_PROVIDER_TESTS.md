# Universal — следующий этап: безопасность нескольких подписок

База: `feature/universal-stage-6-globe`. Проверяется **Universal**, а не production Signet 0.2.6.

## Добавленная регрессионная проверка

Новый UI/instrumentation тест `deletingOneProviderDoesNotDestroyAnotherProviderOrItsSelection` использует две независимые искусственные подписки (локальный SOCKS outbound без секретов и реального подключения). Проверяет:

- создание двух отдельных провайдеров с разными идентификаторами;
- закрепление обеих групп и сворачивание одной;
- сохранение выбранного сервера и его избранного при удалении *другой* подписки;
- удаление устаревших ID из закреплённых и свёрнутых групп;
- удаление активной в списке подписки очищает ссылку на её выбранный сервер;
- удаление искусственных данных в `finally`, без воздействия на настоящие пользовательские источники.

CI теперь требует 5 UI/инструментальных тестов плюс 11 нативных тестов, существующие unit-тесты и матрицу компоновок.

## Не подтверждено и осталось к функциональной приёмке

- Проверка с настоящими Remnawave HTTPS подписками разных провайдеров, включая обновление, замены хостов, expiry/traffic, HWID.
- Работа Xray в реальной мобильной сети, с VPN consent, восстановление после потери сети и отключения приложения.
- Полный JSON с серверным AUTO и сложными маршрутизаторами, без выдуманного клиентского балансировщика.
- Сквозные отрицательные тесты: небезопасный URL, повреждённый JSON, OAuth без согласия, отказ API, пустая подписка, секреты в логах.
- Полная проверка TalkBack на устройстве, сравнение изображения планеты с согласованным макетом и приёмка вертикального вращения.
- Приёмка Google Play и подпись релизной версии.

Это технический этап расширения тестов, **не завершённая приёмка функционала**. Никаких релизов и слияний до устранения замечаний.
