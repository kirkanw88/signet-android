# Signet VPN 0.2.15 — спутниковый вид столицы и установка обновления

Только universal `com.signet.client.external`, code 17. Устанавливается поверх предыдущей universal. Исходный Signet с кабинетом остаётся на 0.2.6.

## Столица с высоты

После подключения планета поворачивается к столице страны сервера и приближается. Когда камера остановилась и снимок готов, выполняется плавный переход к настоящему спутниковому изображению центра столицы MapTiler Satellite. Маркер остаётся в центре, название столицы показано по-английски. Это отдельные детальные снимки, а не растяжение текстуры Земли.

Подгружается только небольшой участок из девяти соседних tiles на zoom 17. Проверенный сервис выдаёт tiles 512×512; итоговый кадр 1024×1024. Показан полный кадр без сильного цифрового увеличения. Снимок архивный дневной: он не выдаётся за прямую трансляцию или текущую ночную съёмку. Доступная детализация зависит от снимков провайдера для выбранного города.

HTTP-кэш в `cacheDir/capital-imagery` ограничен 8 МБ и соблюдает правила cache-control сервиса. Хранятся только используемые участки, а не атлас всех столиц. Загрузка/декодирование выполняются вне UI и GL-thread; сетевые запросы отменяются при смене страны/выходе. Размер одного ответа ограничен 512 КБ, размер tiles — 256/512, суммарное время загрузки — 25 секунд. Клиент/кэш принадлежит ViewModel и закрывается при её освобождении. Старая фотография освобождается после перехода, промежуточные bitmap перерабатываются.

Ошибка снимка не меняет статус VPN: остаётся планета и сообщение «Снимок столицы недоступен». Если страна неизвестна (например AUTO без определённой страны), столица не выдумывается. На снимке отображается атрибуция MapTiler/OpenStreetMap.

## Установка обновления

Во время скачивания прогресс плавно следует реальному количеству байтов. Проверка и установка показывают вращающийся индикатор, пульсацию значка и движущуюся полосу вместо неподвижного «100%». После запуска системного подтверждения этап переключается на установку; окончательный успех/ошибку сообщает Android, фиктивный процент установки не рисуется.

Системное окно Android остаётся системным. Анимация нового кода применяется к обновлениям, которые запускаются **из 0.2.15 и новее**: прежняя установленная версия ещё использует свой интерфейс при переходе на этот выпуск. APK по-прежнему потоково записывается в PackageInstaller и не создаётся в Downloads/файлах приложения.

## Сборка

API-ключ берётся из `SIGNET_MAPTILER_API_KEY` либо локального, исключённого из Git `secrets.properties` (`maptiler.apiKey=...`). В публичных исходниках/отчётах ключа нет. Это клиентский read-only API key MapTiler, не service token; для ограничения такого ключа сервис поддерживает Allowed User-Agent `SignetVPN-Capital/1`. Без ключа сборка возможна, но спутниковые изображения недоступны; подмена картой не выполняется.

Контракты: [MapTiler Tiles](https://docs.maptiler.com/cloud/api/tiles/), [client API keys](https://docs.maptiler.com/guides/developer/credentials/api-key/), [temporary personal cache and attribution](https://www.maptiler.com/terms/cloud/). Текущий подтверждённый слой — `satellite-v2` (пример `satellite-v4` из документации для данного доступа вернул 404).

Проверки и ограничения: [TEST_REPORT](TEST_REPORT.md). Получен реальный снимок Риги; выполнение переходов и установки на физическом Android не проверялось.
