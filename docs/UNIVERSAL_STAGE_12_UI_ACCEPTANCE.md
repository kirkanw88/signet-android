# Universal 0.2.19 — этап 12: визуальная приемка

## Внесено
- Отдельный визуальный стиль Home только для Universal: новый статус с индикатором, карточка локации, выразительная кнопка подключения.
- Информативная композиция поверх 3D-глобуса и подсказка горизонтального свайпа.
- Контур выбранной страны и маркер её столицы доступны уже при выборе сервера, без обязательного VPN-подключения.
- Ручное вращение только по горизонтали (сохранено из этапа 11). Вертикальная прокрутка страницы не заблокирована.
- Номер версии `0.2.19` (`versionCode 21`) и заметная метка `G12` на главном экране.
- Подписки, маршрутизация, ядро Xray, серверы и оригинальная редакция Signet `0.2.6` не изменяются.

## Обязательные условия приемки
- GitHub Actions: Build, runtime instrumentation, 11 нативных тестов и матрица разрешений.
- Посмотреть скриншоты настоящего GLES-рендера в runtime evidence, сравнить компактный/большой экран.
- Физический Android: импорт двух разных подписок, выбор сервера, переключение, реальное подключение и отключение, горизонтальный свайп, вертикальный скролл, ориентация и доступность крупного текста.
- Проверить отсутствие визуальных перекрытий, ошибки EGL, а также отсутствие повреждения данных при обновлении с 0.2.17/0.2.18.
- Production Release только после проверки на физическом устройстве и решения вопроса production-подписи. До этого допустим только pre-release для тестирования.

## Известные ограничения
Автоматический CI не заменяет визуальную приёмку человеком. Сама по себе новая версия не доказывает, что UI соответствует предоставленному референсу.

## Дополнительная визуальная приёмка (замечания по телефону)
- Убрать декоративные надписи с глобуса и над ним.
- При отсутствии подписок вместо «Выбрать сервер» предлагать импорт по ссылке или QR.
- При активном соединении ручные свайпы не вращают Землю.
- При соединении зум не более примерно 1.25×; страна не обводится и не закрашивается, показывается только маркер столицы.
- Компактный единый стиль для главной карточки локации, трафика, списка серверов, шапок подписок, настроек, диалогов импорта и обновления.
- Значение Ping и второстепенная информация не должны визуально конкурировать с названием сервера.
- Для доступности сохранять высоту интерактивных элементов минимум 48 dp; крупные шрифты должны корректно переноситься.
- Версия для проверки на физическом Android: 0.2.20 (code 22). До визуальной приёмки и проверки реального подключения не выпускать стабильный релиз.
