# Рендеринг Земли

OpenGL ES 2.0 выбран вместо Filament: одной сфере и нескольким географическим слоям не нужен крупный scene engine. Сфера — 96×48 сегментов, UV equirectangular, глубина 16 бит. Земля действительно трёхмерная и вращается жестом; нет WebView/GIF. Текстура, география и шейдеры поставляются офлайн.

Земля освещается направленным источником с затемнением ночной стороны. Атмосфера — дополнительная сфера; High добавляет процедурный облачный слой без дополнительных bitmap-текстур. Облака декоративные, не текущие метеоданные. Реальные ночные огни городов не моделируются. Координаты широты/долготы совпадают с UV и контурами. Отдельные географические полилинии/треугольники лежат чуть выше сферы, depth testing скрывает обратную сторону.

Целевая максимальная частота: High 60, Balanced 30, Battery Saver 10. Уменьшение движения выключает автоповорот и волны; пользовательское вращение остаётся. При уходе из Activity/с домашнего экрана GLSurfaceView приостанавливается, EGL context освобождается. CPU bitmap сразу recycle после загрузки на GPU. Для контуров хранится геометрия только выбранной страны; пул всех meshes стран не создаётся. Географический JSON загружается один раз на создание GL-контекста.

Текстура исходно 4096×2048, декодирование ограничено шириной 2048 с RGB565. Источник и SHA — `assets/sources.json`; исходная NASA Blue Marble текстура распространена в примере webgl-earth. Высокое качество не требует её дополнительной копии в кеше приложения.

Скриншоты и измерения эмулятора не доказывают 60 FPS/расход батареи на физическом телефоне. GPU-драйверы, thermal throttling и длительная нагрузка требуют отдельного стенда.
