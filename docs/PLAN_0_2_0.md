# План 0.2.0

База: fc4f885; исходное дерево чистое, ветка feature/android-0.2.0. Production и соседний репозиторий не изменяются.

1. A: удалить локальный алгоритм AUTO, сохранить серверный JSON, стабилизировать идентичность профилей/обновление, явное разрешение камеры и собственный scanner, ограниченный reconnect и контроль живого соединения.
2. B: ServerDisplayModel, CountryFlag, вертикальные группы, поиск/фильтры, Ping/Refresh, настройки проб и отмена, выбор видимых приложений и перенос правил через версионированный безопасный JSON.
3. C: однотонная геометрия, масштаб по размеру страны, звёзды/огни, корректный adaptive launcher с надписью; сохранить ограничения памяти/FPS.
4. D: проверить точный libXray commit, XDrive/MASQUE и backend-варианты; полный JSON без подмены транспорта, проверки ядром и изолированные локальные стенды.
5. E: документированные metadata/headers, описания и сообщения Remnawave, лимиты/HWID и сохранение выбора при обновлении.
6. F: реальные доступные API аккаунта/платежей; при отсутствии native API — рабочий переход в существующий кабинет + точный контракт требуемого backend, без фальшивой авторизации. Обновления приложения: ручная команда и уведомление о новой версии, лимит частоты и подтверждение загрузки.
7. G: security review, meaningful unit/UI/integration tests, strict verification, Lint, Debug/Release, подпись/ABI/manifest, CI, документы и APK 0.2.0.

После каждого этапа — доступные build/test checks и отдельный commit. Runtime/e2e/physical результаты фиксируются отдельно от компиляции. Отсутствующие API/серверы/аппаратные проверки не объявляются готовыми. Список этапов не заменяет выполнение.
