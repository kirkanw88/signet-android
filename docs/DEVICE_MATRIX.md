# Совместимость

Единственное фактически использованное устройство — Android Emulator API 36, Google APIs, x86_64, GLES через SwiftShader. Это не проверка физического ARM-телефона.

Min SDK 26, target/compile SDK 36. Собираются APK arm64-v8a, armeabi-v7a, x86_64. Android 8–15 и физические устройства: NOT RUN. Поддержка этих версий объявлена конфигурацией сборки, но ещё не подтверждена полевым тестом.

Скрипт `scripts/capture-matrix.py` подготовлен для проверки доступности основной кнопки на 360×640, 393×851, 412×915, 600×960, 800×1280, 640×360 и 360×640 с fontScale 1.3. Это размеры окна одного эмулятора, не семь различных устройств. Итоговый запуск BLOCKED: повторно запущенный эмулятор остался ADB offline до загрузки Android. Поэтому результатов этой матрицы нет. Скрипт сохраняет снимки как начальную базу; автоматического сравнения с эталоном нет.

До публичного выпуска нужны реальные ARM64 устройства разных производителей, переходы Wi-Fi/mobile, системный Always-on после перезагрузки, battery saver и длительный фон.
