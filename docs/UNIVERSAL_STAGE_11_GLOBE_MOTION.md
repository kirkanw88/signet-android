# Universal — этап 11: диагональные жесты на настоящем 3D-глобусе

## Основание
Этап 10 (PR #9, `feature/universal-stage-10-globe-acceptance`) завершился зелёными GitHub Actions на коммите `3bed4e97`. Тест впервые подтвердил изменение GLES-углов при реальных вертикальном и горизонтальном свайпах, проходящих через Compose.

## Изменения
- В `GlobeVisualTest.kt` добавлен `firstDiagonalSwipeChangesBothRenderedAxes`: один диагональный свайп, введённый через `performTouchInput` по области `home-globe`, должен изменить **оба** фактически отрендеренных угла (`yaw` и `pitch`) более чем на 3°.
- Тест также проверяет рост счётчика обработанных движений, чтобы не спутать автоматическую анимацию Земли с доставкой события.
- В CI обязательны **8 UI/instrumentation тестов**, плюс прежние 11 нативных проверок Xray/TUN, unit-тесты, Lint, Debug/Release и матрица разрешений.
- Продолжает использоваться 3D-глобус Universal с полностью освещённой Землёй (без ночной стороны), небесно-голубым атмосферным контуром и подсветкой выбранной страны.

## Ограничения
- Эмуляторная проверка ввода не доказывает удобство жестов на физическом устройстве, особенно при прокрутке рядом с планетой.
- Приёмка цвета, соответствия присланному референсу, плавности анимации, GPU FPS/нагрева, крупного текста, TalkBack и экранов с малой высотой остаётся обязательной.
- Релиз и слияние запрещены до устранения замечаний. Никаких изменений в серверных AUTO, Remnawave/Xray маршрутизации и основной редакции Signet 0.2.6.
