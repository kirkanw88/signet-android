# Состояния и анимации

DISCONNECTED — медленное вращение 3°/с, выбранный узел сохраняется. При выборе узла глобус плавно направляется к стране из метаданных; TUN не создаётся. CONNECTING/RECONNECTING — вращение 280°/с параллельно реальному запуску. Нет таймера, устанавливающего CONNECTED.

CONNECTED возникает только из VPN service после запуска ядра и реальной HTTPS-проверки. Вращение замедляется к выбранной стране, подсветка становится зелёной; при явных координатах города показывается маркер и три геодезические волны. Анимация не задерживает доступность реального соединения.

STOP отменяет задачу запуска, сериализует остановку Core/TUN и сбрасывает состояние. ERROR показывает сообщение без конфиденциальной native-ошибки. При смене физической сети и включённом reconnect выполняется новый запуск с debounce 1200 мс. При отсутствии события смены сети автоматического бесконечного цикла повторных подключений нет; пользователь может повторить подключение.

В High есть облака и атмосфера; в Balanced атмосфера; в Battery Saver тяжёлые слои отключены. Accessibility reduce motion отключает вращение ожидания и волны. Android не получает CONNECTED из состояния графики.
