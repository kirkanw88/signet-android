# Signet Universal 0.2.19 — предварительные заметки к выпуску

**Редакция:** Universal (`com.signet.client.external`), Android 8.0+ (API 26), `versionCode 21`.

## Что изменилось
- Главное окно заметно переработано: новый индикатор статуса, акцентная карточка выбранной локации, отдельная крупная кнопка подключения и служебные подписи вокруг глобуса.
- Земля вращается вручную только по горизонтали. Вертикальные жесты предназначены для прокрутки главного экрана; автоматический поворот к выбранной локации сохранён.
- Доработанный дневной рендер Земли и атмосферный контур из этапов 9–10.
- Добавлены настройки качества рендеринга (High/Balanced/Battery Saver) и уменьшения движения в Universal.
- Подписки разных провайдеров остаются разделёнными, настройка сервера и Ping привязаны к источнику.

## Установка для теста
Скачать GitHub Actions artifact `signet-apks` из успешной сборки ветки `feature/universal-stage-12-final-ui`. Выбрать APK `external` нужной архитектуры; на большинстве Android — `arm64-v8a`. Версия на главном экране: `v0.2.19 · G12`.

## Контроль качества
Ожидаются CI Build + 8 Android UI/instrumentation + 11 native VPN tests + viewport matrix, а также проверка реального телефона.
Отладочная подпись GitHub Actions не предназначена для публикации в Google Play. Перед публичным стабильным выпуском требуется настроить управляемое production-signing и проверить обновление без потери профилей.

**Не объявлять релиз стабильным до визуальной приёмки, реальной проверки подключения и проверки upgrade-совместимости подписи.**
