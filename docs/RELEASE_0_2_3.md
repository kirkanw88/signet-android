# Signet Android 0.2.3

## Изменения

- Космос занимает весь экран, включая пространство вокруг планеты и страницы настроек. Фототекстуры, облака, ночные огни и освещение по текущему UTC сохранены.
- При подключении камера сильнее приближает выбранную страну, ориентируясь на столицу. После завершения приближения появляется маркер с английским названием столицы. Это географическая отметка, а не определение расположения сервера. AUTO без известной страны не получает вымышленный маркер.
- Выбранный сервер выделяется рамкой; слово «Выбран» убрано. Значок Ping — спидометр, настройки называются «Настройки Ping».
- Убраны VPN / ANDROID в шапке, строка «HWID всегда включён» и пояснения внизу Оформления. HWID остаётся обязательным. Рамка стеклянной кнопки и её фон используют одну поверхность и форму.
- Адрес кабинета фиксирован: https://signet-cab.com. Старые пользовательские значения игнорируются при загрузке и сохранении.
- В шапке добавлена иконка техподдержки с переходом к @cyber_goos — как в публичном кабинете.
- Трафик/лимит и дата окончания подписки показаны на главном экране для выбранного профиля. Источник — subscription-userinfo Remnawave; отсутствующие значения не придумываются.
- Подписки: вставка HTTPS ссылки из буфера с подтверждением и копирование исходной ссылки из карточки. Приложения через VPN: копирование и вставка AppRouting JSON v1 с предварительным просмотром; файловый обмен сохранён. Clipboard читается только по нажатию, копируемые данные помечены sensitive, размер ограничен.

## JSON и DNS

Signet запрашивает фактический JSON Remnawave через /json. Один Accept заголовок не выбирал этот формат, а стандартное UA-правило панели не включает Signet среди Happ/INCY. Оригинальная ссылка и её query/token сохраняются; fallback на исходную ссылку допустим один раз при 404/405. Ответы 401/403 не обходятся. В списке «JSON» означает полученный JSON, URI остаётся URI. После установки обновите подписку кнопкой обновления в шторке серверов, чтобы получить JSON вместо ранее сохранённых URI.

Системный DNS Android раньше не был связан со встроенным DNS Xray: TUN получал адрес числового DNS/резервного DNS, но DoH/hosts исходного JSON не получали автоматически эти пакеты. В 0.2.3 виртуальный 172.19.0.2:53 перенаправляется на встроенный DNS outbound, сохраняя provider DNS и относительный порядок исходных правил. Резервный DNS без provider dns использует TCP через Xray routing. Добавленный handler исключается из AUTO/observatory prefix selectors с сохранением исходного состава узлов. Bootstrap libXray защищён и привязан к физической сети, HTTPS приложения продолжает идти через VPN. TLS и проверки зависимостей не отключались.

## Проверка и установка

См. [TEST_REPORT](TEST_REPORT.md). Проверены целевые JVM-сценарии, настоящий локальный Xray DNS по TCP/UDP, компиляция шейдеров, Android Lint, сборки Debug/Release и подпись/alignment трёх ABI. Долгий эмуляторный прогон не повторялся по просьбе пользователя. Подключение конкретной подписки и новый интерфейс на физическом телефоне не проверены; Android strict Private DNS отдельно не тестировался.

APK 0.2.3 имеет code 5, package com.signet.client и тот же локальный development-сертификат, что опубликованные 0.2.1/0.2.2. Обновление сохраняет данные при совпадении сертификата установленной копии. Для современных телефонов — arm64-v8a. Производственная инфраструктура и main не изменялись.
