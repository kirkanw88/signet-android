# Signet Android 0.2.1

Главный экран показывает крупную планету в собственной области, выбранный сервер и стеклянную кнопку подключения. Серверы открываются отдельной вкладкой или нажатием на выбранную локацию. Поля не перекрывают планету. В альбомном режиме планета и управление расположены рядом. Стекло использует статические градиенты и тонкую светлую кромку, не требует снимка фона, blur-буферов или дополнительного непрерывного таймера.

Список серверов плоский. Города и игровые имена сохраняются; при одинаковых подписях добавляются номера в порядке подписки. Идентификаторы серверов, JSON и исходный порядок не меняются. Обновление и выполняющиеся пробы отображают прогресс. Форматирование `profile-title` и `announce` сохраняет абзацы, отступы и переносы; для уже сохранённых плоских заголовков требуется обновить подписку.

HWID всегда включён, включая миграцию со старого выключенного значения. Заголовки передаются только исходному HTTPS-хосту подписки; при переходе на другой хост стабильный ID не раскрывается.

Проверка VPN использовала `settings.probes.url`, в том числе при TCP-пинге. Это связывало два разных действия: TCP-пинг проверяет порт, а HTTPS проверяет передачу данных через TUN. Типовой Remnawave split с `geosite:google` блокирует прежний gstatic URL. Теперь адрес проверки соединения отдельный, по умолчанию `https://example.com`, доступен в настройках. Пользовательская маршрутизация, TLS и обязательный HTTPS для статуса CONNECTED сохранены. Адрес должен разрешаться политикой конкретного профиля.

QR-камера использует mixed normal/inverted decoder и непрерывный автофокус. Удалена дополнительная декоративная рамка, не совпадавшая с фактической областью декодирования. Неподходящий QR больше не блокирует дальнейшее сканирование. Импорт из изображения пробует normal/inverted luminance и два binarizer, сохраняет лимиты памяти и освобождает bitmap. Известные `happ://add/`, `v2raytun://import/`, `streisand://import/`, `v2rayng://install-config?url=` и `signet://import?url=` раскрываются только в безопасный HTTPS URL; обычный URL не декодируется повторно, токен сохраняется. Перед импортом остаётся подтверждение.

Выпуск подписан прежним локальным development-сертификатом. Производственный ключ и публикация public GitHub Releases требуют внешней настройки; приватный репозиторий не менялся на публичный. Физическая камера и ARM-устройства в этой среде недоступны; эмуляторные и синтетические проверки не заменяют их. Результаты: [TEST_REPORT](TEST_REPORT.md).
