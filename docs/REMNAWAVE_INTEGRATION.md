# Подписки Remnawave

Приложение получает только пользовательскую subscription URL. Панель и production-инфраструктура не изменяются, административный API не используется. Полный Xray JSON, JSON arrays, share links и Base64 импортируются отдельно: полный JSON не проходит через конвертер узлов, удаляющий routing и DNS.

Разрешены HTTPS и максимум пять HTTP redirects с сохранением HTTPS. Тело ограничено 4 МБ. Собственного HTTP-кеша нет. `profile-title` (включая `base64:`) и `subscription-userinfo` (upload/download/total/expire) отображаются в карточке. Обновление явно запускается пользователем или WorkManager каждые 6 часов при доступной сети. Ошибка загрузки оставляет предыдущую рабочую подписку.

Заголовки клиента: User-Agent `SignetVPN/0.1.0 (Android …)`, Accept JSON/text; опционально X-Hwid, X-Device-Os, X-Ver-Os, X-Device-Model. Случайный UUID установки сохраняется в зашифрованном хранилище. Это отдельная идентичность клиента Signet, не подделка HWID Happ/Incy. Переустановка создаёт новый ID; сервер может учитывать его как новое устройство. Фактическая совместимость с текущей политикой production Remnawave требует пользовательской тестовой подписки и отдельной проверки.

Для AGE пользователь вводит secret key. Расшифрование выполняет libXray, ключ сохраняется только внутри зашифрованной записи для дальнейшего обновления. Проприетарные `happ://crypt…` и `incy://crypt1` не заявлены совместимыми; открывайте исходную HTTPS-подписку. Нет административных токенов и private provider APIs.

Проверенные источники интеграционных форматов: [Incy subscription docs](https://docs.incy.cc/), [HWID](https://docs.incy.cc/hwid/), [Happ developer docs](https://www.happ.su/main/dev-docs.md). Эти документы описывают другие клиенты и не доказывают контракт конкретного Signet-сервера.

Страна определяется явным `signet.countryCode` либо флагом/структурированным ISO-кодом названия. Город и координаты — только из явных `signet.city`, `latitude`, `longitude`. Геолокация входного IP не используется. Если город неизвестен, он не выдумывается; маркер города не рисуется. Для неизвестной страны отображается «Локация не указана».
