# Universal — следующий этап: образ планеты и жесты вращения

## Реализовано в исходниках
- Для Universal жест, начатый **на поверхности планеты**, всегда выбирает вращение, независимо от первой оси движения. Прежде вертикальное движение передавалось родительской вертикальной прокрутке.
- При вращении вверх/вниз используется существующая модель `pitch`, ограниченная диапазоном `-85°...85°`; горизонтальное вращение использует `yaw`.
- Прокрутка остальной части главного экрана остаётся доступна при начале жеста вне области OpenGL-планеты.
- Поведение замороженной Signet-редакции сохраняется: параметр `rotateVertical` включён только при `!BuildConfig.SIGNET_ACCOUNT`.
- Новые unit-тесты для первичного вертикального и диагонального жестов.

## Отдельное требование: визуальный образ Земли из согласованного макета
Пользователь попросил перенести **то же изображение планеты**, что было в ранее показанном ассистентом макете интерфейса. **Точное исходное изображение макета отсутствует в доступных артефактах текущей сессии. Замена текстуры не выполнена.** Нельзя подменять исходный макет произвольной картинкой.

Для завершения задачи: получить исходный кадр/файл согласованного макета, изучить дневную/ночную стороны и оформление, воспроизвести тот же стиль на настоящем 3D-глобусе без натяжки обычного перспективного кадра на сферу. Обновить `earth.jpg`/шейдеры, если исходный стиль этого требует, без нарушения лицензионной чистоты. Сохраняются выбор локации, границы стран, освещение и плавное вращение.
