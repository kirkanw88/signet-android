# Signet VPN 0.2.8 — универсальная версия

Только `external`, пакет `com.signet.client.external`, code 10. Signet с кабинетом остаётся на 0.2.6 без нового выпуска.

- В «Настройки → Оформление» появились светлая, тёмная и системная темы. Выбор сохраняется в DataStore. Для прежних установок по умолчанию остаётся тёмная тема.
- Палитра применяется к главному экрану, настройкам, серверной шторке, импорту, приложениям, Ping, журналу, JSON-редактору и окну обновления. Цвет системных значков меняется вместе с темой. Фото Земли и космос внутри её области сохраняются, в светлой теме эта область оформлена отдельной панелью. Камера QR сохраняет тёмные элементы управления поверх изображения камеры.
- В шапке главного экрана показывается установленная версия. Надпись «Сторонние подписки» удалена.
- Универсальный updater при открытом приложении/возвращении на экран проверяет актуальность данных: успешный результат свеж 15 минут, неудачная попытка допускает повтор через 2 минуты. Проверка по кнопке не ждёт автоматического интервала; от двойного нажатия оставлена короткая пауза 3 секунды.
- «Позже» закрывает автоматическое окно этой версии, а баннер и кнопка обновления остаются доступны. В настройках показывается найденная версия.
- Восстановление кеша больше не сбрасывает остальные поля состояния проверки. TLS, проверка размера/SHA-256, редакции и установка через PackageInstaller сохранены.

Причины прежнего поведения: универсальная 0.2.6 читает общий GitHub latest, который зафиксирован на Signet 0.2.6 для совместимости старых APK; 0.2.7 уже использует отдельный список Releases, но хранила результат попытки на сутки и проверяла только при запуске. После «Позже» раньше скрывался и баннер. Это отдельные условия, а не доказательство сетевой ошибки на телефоне.

Для перехода с 0.2.6 установите `signet-external-0.2.8-arm64-v8a.apk` поверх приложения, без удаления. В 0.2.7 можно нажать «Проверить обновление» после публикации либо установить этот APK вручную. Автоматическая политика 0.2.8 начинает действовать после её установки. Если уже установлена 0.2.8 и более нового выпуска нет, уведомление не должно появляться.

Нет нового фонового сервиса или периодического фонового задания: таймер действует только при STARTED lifecycle. При свежем результате он читает локальные данные, не делает запрос GitHub. Не добавлены bitmap/blur buffers, запросы к кабинету или новые зависимости.

Проверки и ограничения: [TEST_REPORT](TEST_REPORT.md). [Другие архитектуры](https://github.com/kirkanw88/signet-android/releases/tag/v0.2.8).
