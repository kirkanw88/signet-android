# Signet VPN 0.2.12 — группы подписок и планета

Только универсальная редакция `com.signet.client.external`, code 14. Установите APK поверх текущей universal: подписки и настройки сохраняются.

## Несколько подписок

В разделе «Подписки» и в нижней шторке выбора серверов каждая подписка показана отдельной группой. Нажмите на шапку, чтобы свернуть или развернуть серверы. Состояние сохраняется после перезапуска. Поиск временно раскрывает подходящие группы, не меняя сохранённое состояние.

«Добавить» открывает прежнее меню буфера/QR. Поддерживается до восьми подписок, до 500 профилей и до 8 МБ конфигураций суммарно. Ленивый список создаёт строки по мере необходимости. У каждой группы свои лимит и срок, обновление и Ping. Обновление сохраняет порядок групп и существующий выбор сервера; одинаковые серверы из разных источников имеют независимые идентификаторы.

В меню ⋮ группы доступны «Закрепить подписку», «Экспорт ссылки» и «Удалить подписку». Закреплённые группы находятся сверху, отмечены булавкой, сохраняются после перезапуска; открепление возвращает обычный порядок. Закрепление не раскрывает группу и не меняет выбранный сервер. Удаление требует подтверждения и затрагивает только выбранную подписку; если используется её сервер, VPN отключается.

## Планета после смены темы

GL-view создаётся в `AndroidView.factory`, освобождается через `onRelease` и наблюдает жизненный цикл своего экрана. Состояния attach/resume/pause/detach обрабатываются без повторного использования остановленного View. Смена темы обновляет параметры рендера без отдельной команды pause. При освобождении GPU-контекст не удерживается для старого экрана.

Проверки модели жизненного цикла и сборки не заменяют проверку на телефоне: точное зависание на устройстве не воспроизводилось. Результаты: [TEST_REPORT](TEST_REPORT.md).

Контракт сверён с официальными [рекомендациями AndroidView](https://developer.android.com/develop/ui/compose/migrate/interoperability-apis/views-in-compose) и [API onRelease](https://developer.android.com/reference/kotlin/androidx/compose/ui/viewinterop/AndroidView).
