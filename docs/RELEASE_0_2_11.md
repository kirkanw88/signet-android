# Signet VPN 0.2.11 — главный экран и Ping

Только universal `com.signet.client.external`, code 13. Signet с кабинетом остаётся на 0.2.6, production не меняется.

## Главный экран

Прежняя фиксированная высота планеты (`viewport - 230 dp`, минимум 280 dp) не учитывала реальную высоту названия хоста, лимита, срока, сообщений и трафика. Теперь сначала измеряются статус и весь блок управления; планета получает оставшееся место. При очень крупном шрифте/малой высоте доступна прокрутка без наложения элементов. В landscape правая панель прокручивается независимо.

Трафик показан отдельной карточкой над кнопкой подключения: отправка/получение в Б/с, КБ/с или МБ/с и общие объёмы. Скорость считается по разнице счётчиков и реальному времени между выборками, а не выдаётся из общего количества байтов. Первая выборка, сброс счётчиков и откат времени дают нулевую скорость. Предпочтительно используются счётчики TUN inbound; при их отсутствии — прежние outbound counters. Это скорость между выборками, не отдельный speed test.

## Ping при выключенном VPN в режиме по умолчанию

В коде найдены два пути общего сбоя: ошибка запуска одного конфига срывала всю native batch, а существующие геоданные принимались без проверки после потенциально прерванного копирования. Конкретный случай телефона без native-диагностики не воспроизводился.

- При общем сбое batch каждый обычный профиль проверяется отдельно. Если ответ batch нормальный, дополнительных вызовов нет; единственный неработающий профиль не повторяется. Для рабочих профилей используются только реальные результаты libXray, фиктивная задержка не подставляется.
- AUTO проверяется отдельно полным профилем, не переводит остальные серверы в полный/последовательный режим. Его DNS/routing/balancers сохраняются.
- Геоданные сверяются потоковым SHA-256 с ресурсами установленного APK. Повреждённая копия восстанавливается через проверенный временный файл и atomic move под межпроцессной блокировкой. Ранее существовавшая копия не заменяется неполными данными. Проверка выполняется один раз на процесс; временные имена фиксированы, история копий не накапливается.
- Подготовка полного профиля включена в обработку ошибок каждого сервера. Коды различают ошибку профиля, ядра, геоданных, DNS измерителя и сети. В ответ/журнал не передаются native error text, URL, ключи или адреса серверов.
- Инициализация native DNS может использовать следующий объявленный сетевой resolver при ошибке настройки первого. Пиннинг IP сайта, отключение TLS и изменение настроек проверок не добавлены.

Установите APK поверх текущей universal. Подписку удалять или заново добавлять не нужно.

Проверки и ограничения: [TEST_REPORT](TEST_REPORT.md). На физическом Android, вашей подписке и реальном провайдере Ping после исправления ещё не проверен.

Сверены контракты: [libXray pingBatch](https://github.com/XTLS/libXray/blob/main/xray/ping_batch.go), [Invoke response](https://github.com/XTLS/libXray/blob/main/invoke.go). Native bundle и Dependency Verification не менялись.
