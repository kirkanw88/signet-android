# Universal — этап 5: масштабирование и доступность

Базовая ветка: `feature/universal-stage-4-layout`, CI успешен.

## Изменения
- На крупных системных шрифтах (от 150%) строка сервера выделяет больше места под имя и транспорт: описание может занимать две строки, справа остаётся доступная кнопка избранного с областью нажатия 48dp.
- При шрифтах от 150% декоративный индикатор выбора справа скрывается; состояние остаётся в TalkBack semantics (`selected`, `stateDescription`, `Role.RadioButton`). Это не меняет выбор сервера.
- В матрицу эмулятора добавлены экраны 320px и системные шрифты 160%/200%; отдельно фиксируется необходимость прокрутки к основной кнопке, чтобы не путать полностью недоступный элемент с доступным после прокрутки.
- Защищены исходные имена провайдерских серверов, отсутствие группировки по странам и серверный AUTO. Не меняются Xray JSON, ноды и конфигурация.

## Обязательная приёмка
1. GitHub CI: debug/release, native и UI инструментальные тесты, скриншотная матрица.
2. Просмотр снимков `320x640-font-1.6`, `360x640-font-2.0`, `412x915-font-2.0`, landscape.
3. Ручное тестирование TalkBack: «Выбран»/«Не выбран», избранное, порядок навигации, корректность оглашения подписок и кнопок.
4. Проверить контраст обеих тем, крупную клавиатуру при импорте, возможность нажать Connect и закрыть ошибку/баннер.
5. Физический Android для жестов глобуса, Ping, импортов, подключений и HWID.

Матрица размеров ниже задана в пикселях эмулятора при плотности 160 dpi, а не в dp при произвольной плотности. CI не заменяет оценку внешнего вида и TalkBack на реальном устройстве.
