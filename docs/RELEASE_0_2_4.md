# Signet Android 0.2.4

## Интерфейс

- Импорт и экспорт подписаны текстом. «Добавить подписку» открывает два действия: вставить из буфера или сканировать QR.
- Импорт приложений принимает обычные строки/CSV, JSON-массивы и собственный Signet JSON. Для списков без режима требуется явно выбрать «Только эти через VPN» или «Эти без VPN». Формат с per-app-proxy headers поддерживается по опубликованному контракту Happ/Incy; remote URL не скачивается. Вставленный пример по строкам распознаётся; повреждённая строка с приписанным временем 22:01 показывается среди исключённых, имя пакета не угадывается. Markdown-ссылки принимаются только при совпадении label и host. В публичные fixtures не включён полный список приложений пользовательского устройства.
- Редактор Xray — отдельный экран, 4 пробела, моноширинный шрифт, номера строк, прокрутка по обеим осям и кнопка форматирования. Проверка настоящим ядром перед сохранением сохранена.
- В Подписках показана текущая подписка, без Remnawave заголовка/announce и технических строк DNS/JSON/Xray. Баланс, устройства, настройки, импорт/экспорт оформлены кнопками-строками.
- Список серверов ближе к примеру пользователя: компактная шапка и строка трафика, описания, время ответа и стрелка; поиск/сортировка раскрываются через меню. Выбранный сервер выделен рамкой. Национальные флаги — локальные PNG, AUTO — отдельный синий флаг со звездой вместо глобуса. Национальная страна для AUTO не выдумывается. Прежние правила названий стран/номеров/Игровой/Signet_White сохранены. Удержание строки добавляет/убирает избранное.

## Планета

Дополнительные day/night карты 8192×4096 дают в четыре раза больше исходных пикселей по каждой оси, чем прежняя карта 2048×1024. Полные 8K bitmaps не декодируются: BitmapRegionDecoder читает только регион 2048×2048 вокруг столицы, RGB565, по одному bitmap за раз; CPU bitmap сразу освобождается. Две GPU detail textures заменяются при смене региона, не накапливаются в cache. При меньшем GL_MAX_TEXTURE_SIZE применяется downsampling. Деталь плавно смешивается с базовой текстурой при zoom, fragment highp используется при наличии. Zoom усилен с 2.05–2.7 до 2.6–3.15; камера остаётся снаружи атмосферы. Огни ночных городов и текущая солнечная сторона сохранены. Реальная чёткость/FPS на конкретном Android GPU не измерялись.

Карты: [Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/), NASA-derived, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); license notice включён в APK, source/SHA в assets/earth-detail-source.json.

## Общий аккаунт и поддержка

Подготовлен backend `/api/mobile/v1` в локальном кабинете: вход через существующий Telegram/Google/Яндекс с PKCE, короткий bearer access, вращаемый refresh, общий баланс/подписки, устройства, явное автопродление и поддержка. Бот-only и кабинет-only аккаунты поддержаны без обязательной привязки Telegram. При существующей подтверждённой привязке owner заново разрешается на каждом запросе.

Android использует нативные экраны баланса, устройств и чата с фото/историей — без перехода в Telegram для переписки. Поддержка использует те же backend store, request_id dedupe и operator notification queue, что кабинет и бот. Просмотр хранит только одну страницу 50 сообщений; изображения открываются по одному, без дискового HTTP cache. Токены и PKCE pending — отдельный AES-GCM / Android Keystore vault. Вход и платёжный checkout используют системную браузерную панель; пароль, cookies и payment secrets в APK не извлекаются. Пополнение и изменение тарифа продолжают проверенный web checkout; это не новый native payment API.

**Backend ещё не развёрнут в production и выключен по умолчанию.** До согласованного развёртывания код аккаунта в APK покажет недоступность API. Подписки, импорт и VPN работают независимо. Миграция добавляет две таблицы к существующей общей БД; production и main не менялись. Backend source bundle предоставляется локально отдельно, не публикуется с закрытым кодом кабинета в публичном Android GitHub.

## Обновления

Новая версия открывает стилизованное окно: текущая/новая версия, статус и прогресс. APK передаётся прямо в Android PackageInstaller session, без браузерной загрузки GitHub и без отдельного APK в Downloads/files/cache. Проверяются public GitHub release/ABI, HTTPS redirect allowlist, размер и SHA-256; Android проверяет ожидаемый package, подпись и допустимость обновления. Установка требует обычного разрешения источника и системного подтверждения; Play Protect не обходится.

При ошибке/отмене сессия abandon удаляет staged data; при успехе Android завершает свою сессию, MY_PACKAGE_REPLACED очищает метаданные. Startup recovery удаляет незавершённые и устаревшие собственные сессии. Временное место системному установщику всё равно нужно: обещания обновить приложение совсем без записи APK в хранилище нет. Этот механизм начнёт работать после установки 0.2.4; прежний уже установленный 0.2.3 не меняет свой старый updater до обновления.

Проверки и ограничения — [TEST_REPORT](TEST_REPORT.md). Физический Android, полный цикл self-update и production OAuth/API не тестировались; длительный emulator/CI не повторялся по просьбе пользователя.
