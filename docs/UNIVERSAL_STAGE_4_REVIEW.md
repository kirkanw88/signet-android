# Universal — этап 4: стабильность главного экрана

База: успешный CI этапа 3, коммит `964ae73a` в `feature/universal-stage-3-ux`.

## Внесено
- Для Universal баннер доступного обновления выводится поверх содержимого и не добавляет новую строку к вертикальному макету Home. Положение закреплено ниже верхней панели; блок скрывается за пределами главного экрана, где обновление доступно через окно установки.
- Для Universal ошибка соединения раскрывается по действию «Подробнее» (если текст достаточно длинный) и снова сворачивается. Сохраняются действия перехода к смене сервера и диагностике.
- Signet-flavor сохраняет прежнюю схему размещения баннера и текст ошибок.

## Осталось проверить
- Screenshot/physical-device acceptance на маленьком экране, при доступном обновлении, с развернутой ошибкой и клавиатурой.
- Баннер не должен перекрывать основную кнопку подключения; TalkBack должен находить кнопку «Обновить» и «Позже».
- Сетевые ошибки должны отображаться безопасно, без ссылок подписки, токенов и конфиденциальных данных.
- 320/360/412 dp, landscape, 1.3–2.0 font scale, обе темы, жесты планеты.
- CI build/runtime и физические Android-проверки обязательны до слияния.

Изменения не затрагивают Xray, routing, Remnawave, AUTO, ноды, замороженный Signet 0.2.6, signing и release.
