# Signet VPN 0.2.14 — быстрое добавление и меню подписки

Универсальная редакция `com.signet.client.external`, code 16. Устанавливается поверх предыдущей universal с сохранением данных.

- На главном экране рядом с настройками появилась кнопка **+**. Она открывает меню «Вставить из буфера обмена», «Отсканировать QR-код», «Добавить вручную» без перехода в раздел подписок. Ручной ввод открывает существующий диалог ссылки/конфигурации. Доступные методы используют тот же импорт с согласованием полного JSON из 0.2.13. При загрузке и достижении лимита восьми подписок кнопка недоступна.
- Из главного меню настроек универсальной версии удалён дублирующий пункт «Серверы». Выбор сервера остаётся в шторке на главной и в разделе «Подписки».
- В «Оформлении» удалён пункт «Уменьшить движение» и пустая карточка бывших настроек качества. Для universal применяется обычная анимация; ранее сохранённый переключатель больше её не ограничивает. Светлая, тёмная и системная темы остаются.
- В ⋮ каждой подписки добавлена **«Настройка»**: просмотр полной ссылки без редактирования, «Копировать ссылку», «Закрепить/Открепить подписку», «Удалить подписку». Закрепление и удаление также доступны прямо в ⋮. Переключатель отражает текущее состояние закрепления.
- Булавка закреплённой подписки находится в углу кнопки ⋮ и не занимает место перед названием. Положение и доступная ширина названия одинаковы в обоих состояниях.
- Удаление по-прежнему требует подтверждения и затрагивает одну подписку; при её активном соединении VPN отключается. Для импорта из локальной конфигурации вместо отсутствующей ссылки показано пояснение.

Изменения интерфейса проверены компиляцией и Android Lint; физический Android/QR/буфер обмена в этом выпуске не проверялись. Новые тесты для простых UI-действий не добавлялись. Результаты: [TEST_REPORT](TEST_REPORT.md).
