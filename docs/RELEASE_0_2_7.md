# Signet VPN 0.2.7 — универсальная версия

Активная разработка продолжается только в `external`, пакет `com.signet.client.external`, code 9. Signet с кабинетом остаётся на опубликованной 0.2.6/code 8; новый APK этой редакции не выпускается.

Исправления Ping:

- Нативный процесс проверки получает DNS физической сети и привязывает исходящие сокеты к ней; при активном VPN сокеты защищаются от повторного попадания в туннель. Раньше Ping только защищал сокеты, но не настраивал resolver libXray, в отличие от рабочего VPN. DNS устанавливается заново перед очередным полным профилем. При отсутствии DNS в LinkProperties используется IP DNS из настроек.
- Предпочтение активной физической сети, затем validated Wi-Fi/сотовой сети вместо первого элемента `allNetworks`.
- TCP перебирает полученные IPv4/IPv6 адреса в пределах одного таймаута, закрывает сокеты после каждой попытки. Раньше проверялся только первый адрес.
- Ошибка IPC/запуска проверки не считается отсутствием ответа от всех серверов. Обрыв привязки к изолированному процессу повторяется один раз. В списке различаются сбой Ping, DNS, TLS, таймаут и отсутствие сети. Неопределённый результат не объявляет сервер недоступным и не меняет выбранный сервер.
- HTTPS full-profile и HTTPS endpoint считают любой ответ с корректным TLS успешным установлением соединения, в том числе HTTP 403/451/503. Проверка сертификата сохраняется; переходы по redirects отключены. URL полного/исходящего Ping по умолчанию остаётся `https://www.gstatic.com/generate_204`.

Исходная реализация ProbeService сохранена в source set `signet`; исправленная реализация — в `external`. Процесс проверки по завершении освобождается, как прежде. Нет дополнительных периодических проверок, безусловных повторов серверов и новых зависимостей.

Это исправления найденных путей отказа в коде. Без журнала и физического устройства причина наблюдаемого у конкретного пользователя случая не подтверждена. Ограничения и результаты: [TEST_REPORT](TEST_REPORT.md).

## Обновление

Установить `signet-external-0.2.7-arm64-v8a.apk` поверх универсальной 0.2.6, без удаления приложения. Остальные ABI доступны в этом же выпуске.

Начиная с 0.2.7 универсальный updater читает последние 10 публичных Releases, отбрасывает draft/prerelease/неподходящие APK и выбирает старшую совместимую версию external. Проверки источника, размера, SHA-256 и установка через PackageInstaller сохранены. Выпуск 0.2.7 публикуется без смены `/releases/latest`: там остаётся совместная 0.2.6, чтобы старые версии Signet не получили APK другого пакета. Поэтому переход universal 0.2.6 → 0.2.7 выполняется вручную по ссылке на APK; дальнейшие обновления доступны из приложения. Ранее опубликованные assets не меняются.

## Проверка и упаковка

`./gradlew --dependency-verification strict :core:test --tests com.signet.core.AppReleaseTest :app:testExternalDebugUnitTest :app:lintExternalDebug :app:assembleExternalDebug :app:assembleExternalRelease`

`python scripts/verify-apks.py --edition external`

`python scripts/package-release.py --edition external`

Справочные контракты: [Android Network](https://developer.android.com/reference/android/net/Network), [libXray Android DNS API](https://github.com/XTLS/libXray/blob/main/android_wrapper.go). Нативное ядро не обновлялось.
