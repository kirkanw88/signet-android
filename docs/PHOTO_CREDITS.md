# Фотографии достопримечательностей

Фотографии в `app/src/external/assets/landmarks/` имеют собственные лицензии CC BY, CC BY-SA, CC0 или статус public domain, указанные для каждого файла отдельно. Они не получают автоматически лицензию программного кода приложения.

Полный список авторов, лицензий, ссылок на исходные страницы и условий лицензий: [landmarks.json](../app/src/external/assets/landmarks.json). В приложении эти данные доступны по кнопке информации над фотографией.

Источники файлов зафиксированы в [landmark-files.json](../scripts/landmark-files.json). Это отобранные файлы Wikimedia Commons; случайный результат поиска не используется при обновлении каталога. Для Белмопана и Ниамея показан вид города, что прямо указано в интерфейсе; остальные записи подписаны названием выбранной достопримечательности.

Изменения для приложения: фотографии перекодированы в WebP с quality 80, без кадрирования. К производным файлам сохраняются соответствующие требования исходной лицензии, включая атрибуцию и ShareAlike. Это обычные архивные фотографии, не трансляция и не обещание актуального состояния объекта.

Восстановление или обновление: `python scripts/fetch-landmark-photos.py --refresh` (нужен Pillow и сеть). Скрипт получает ограниченные thumbnails и метаданные [Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo), проверяет разрешённую лицензию и записывает автора/источник. Запросы последовательные с идентификатором проекта согласно [User-Agent policy](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy). Обычный запуск сохраняет существующие ресурсы и не скачивает их повторно.
