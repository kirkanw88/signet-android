# Безопасность

Конфигурации, URLs, HWID установки, AGE-ключи и оригиналы профилей находятся внутри AES-256-GCM записи Room; случайный IV на каждую запись, Keystore alias `signet.profiles.v1`. Android backup отключён. Сырые HTTP/native ошибки не экспортируются; diagnostic report содержит статусы/версии/количество узлов, без адресов серверов, UUID пользователей и subscription links. Нельзя экспортировать сам профиль в публичные сообщения: он по природе содержит секреты.

Сервис VPN защищён BIND_VPN_SERVICE; основной экран — единственная пользовательская exported Activity. Probe service не экспортирован. Входящий deep link открывает диалог импорта, а не подключает VPN автоматически. Подписки только HTTPS, без отключения TLS verification; обход для cleartext разрешён исключительно loopback metrics.

Foreground type systemExempted используется только после VPN consent. Подавление одного Lint false positive документировано ссылкой на Android: для user-configured VPN не требуется разрешение точных будильников. Лишнее alarm permission не запрашивается.

Исходящие сокеты Core защищаются от routing loop. TUN принимает обе IP семьи; отсутствие IPv6 на узле не приводит к намеренному обходу VPN через IPv6. Настоящий kill switch предоставляют Android Always-on / Block connections without VPN, включаемые пользователем в системных настройках.

В 0.2.0 основной SOCKS listener удалён. Временный probe HTTP proxy защищён случайным паролем на каждый запуск и уничтожается вместе с процессом. Xray metrics остаётся на loopback TCP: Android не даёт приватности по UID для таких портов. Метрики содержат технические счётчики и стандартные debug endpoints Xray. Это известное ограничение для недоверенных локальных приложений; требуются дальнейшая изоляция/аутентификация. Ответ метрик ограничен 512 КБ; файловые debug-логи отключены и в Debug.

OAuth backend XDrive требует отдельного согласия при импорте; случайный deep link его не наследует. Проверка публичных обновлений не отправляет HWID, VPN URLs или токен GitHub, принимает ссылки только официального репозитория и не устанавливает APK автоматически. Production key и публичный канал публикации не настроены. Подробный review — SECURITY_AUDIT_0_2_0.md.

APK подписан сертификатом разработки. Production signing, аудит всех транзитивных native-зависимостей на CVE, review сложных произвольных Xray-конфигураций и тесты утечек на физических устройствах не заявлены завершёнными. Совпадение SHA-256 с официальным release asset защищает целостность загрузки, но не заменяет аудит исходников.
