# Signet VPN 0.2.17 — обычные фотографии и вращение планеты

Universal `com.signet.client.external`, code 19. Установите поверх текущей universal. Исходный Signet с кабинетом остаётся на 0.2.6.

## Фотографии

Вместо спутниковых tiles после подключения и приближения планеты показывается обычная фотография местной достопримечательности: город, название места, автор и лицензия. Все 193 изображения каталога включены в APK, поэтому при подключении не нужны MapTiler, API-ключ, DNS или доступ к фотосервису. Для Белмопана и Ниамея используется вид города с соответствующей подписью. Фотографии архивные, не в реальном времени.

Кнопка «Планета» возвращает интерактивную Землю, «Фото» снова открывает фотографию. В памяти декодируется только текущий кадр и кратковременно исходящий кадр перехода; каталог не загружается в RAM целиком. Подготовленные фото занимают 19 566 932 bytes (около 18,7 МиБ) в пакете. Растущий сетевой кэш больше не нужен; прежний кэш `capital-imagery` очищается при первом открытии фото.

Изображения размещены только в external source set. Автор, источник, лицензия и изменения формата перечислены в [PHOTO_CREDITS](PHOTO_CREDITS.md) и доступны в приложении по кнопке информации.

## Свайпы

Пока направление не определено, родитель не перехватывает жест. Горизонтальный свайп вращает планету, вертикальный в portrait передаётся прокрутке. В landscape, где у планеты нет прокручиваемого родителя, доступны обе оси вращения. Учтены начальный диагональный шум, смена активного пальца, отмена и повторный жест.

Под видимой фотографией GL-view не получает жесты и не рисуется непрерывно. Возврат к планете восстанавливает обычный рендер без пересоздания GL-view/дополнительной паузы контекста.
