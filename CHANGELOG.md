## 0.2.3 — 2026-11-18

- Системный DNS через встроенный DNS Xray с сохранением provider DoH/hosts; отдельный защищённый bootstrap физической сети. Настоящая HTTPS/TLS-проверка сохраняется.
- Remnawave запрашивается явно в режиме /json; JSON/URI в интерфейсе обозначает реальный формат.
- Космос на весь экран, более сильное приближение к столице и маркер с английским названием после завершения движения.
- Выбор сервера рамкой, спидометр Ping, убраны VPN/ANDROID, статус HWID и нижний текст Оформления. Рамка стеклянных кнопок совпадает с поверхностью.
- Фиксированный адрес кабинета, иконка поддержки как на странице кабинета, трафик и срок Remnawave на главном экране.
- Импорт/экспорт ссылки подписки и списка приложений из буфера с подтверждением.


Выбор сервера в анимированной нижней шторке, иконки обновления и задержки, главное меню в настройках. Новые карточки настроек, отдельная диагностика и ограниченный журнал подключения. Одна кнопка подключения/отключения. Названия стран, номера, «Игровой», исключение Signet_White и исправленное распознавание Signet_Auto. Описание транспорта `VLESS / XHTTP / TLS / JSON`.

Планета поворачивается к стране и приближается без быстрого вращения. Фототекстура с облаками, астрофотографический фон и ночные огни по текущему положению Солнца. Исправлены ложные отказы HTTPS на HTTP-кодах 4xx/5xx, добавлена ограниченная готовность TUN/DNS. Репозиторий открыт для публичных GitHub Releases.

# 0.2.1 — 2026-11-18

Увеличена планета: отдельная область главного экрана без наложения полей, список серверов перенесён на вкладку «Серверы». Кнопки получили полупрозрачное стекло с бликом без blur-буферов. Убрана группировка серверов; одинаковые названия различаются порядковыми номерами, города и игровые названия сохраняются.

HWID всегда передаётся исходному HTTPS-хосту подписки, прежний opt-out игнорируется. Сохранены переносы строк и отступы заголовков/объявлений Remnawave. Добавлены индикаторы обновления и каждой выполняющейся пробы. HTTPS-проверка VPN отделена от настроек Ping: TCP-пинг не заменяет проверку трафика. QR поддерживает инвертированные изображения и известные HTTPS launcher-ссылки, камера использует непрерывный автофокус и mixed decoder.

# 0.2.0 — 2026-11-18

Delivered AUTO без локального выбора, группы серверов и локальные флаги, четыре режима ограниченных проб, QR permission/lifecycle/image import, перенос per-app JSON, Remnawave headers и проверка routing templates. Исправлен перенос ingress sniffing в TUN/probe. Public GitHub update check/баннер и существующие browser account/payment flows. Однотонная геометрия/zoom/globe night и adaptive icon.

Официальное ядро сохранено: XDrive/MASQUE full JSON и проверки параметров, отдельное согласие для OAuth. Добавлены транспортный стенд и Android instrumentation job. Убраны лишний SOCKS listener и debug log, ограничены QR/metrics/update metadata. Приёмка ограничена TEST_REPORT; native account API/public releases/physical tests не объявляются готовыми.

# 0.1.0 — 2026-11-17

Первый Android-проект Signet VPN: Compose, native Xray TUN, encrypted subscriptions, per-app routing, HTTP probes, AUTO, OpenGL globe, точный вектор исходного логотипа. Поставляется устанавливаемая сборка разработки; результаты тестов и ограничения в docs/.
