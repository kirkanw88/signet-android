# 0.2.0 — 2026-11-18

Delivered AUTO без локального выбора, группы серверов и локальные флаги, четыре режима ограниченных проб, QR permission/lifecycle/image import, перенос per-app JSON, Remnawave headers и проверка routing templates. Исправлен перенос ingress sniffing в TUN/probe. Public GitHub update check/баннер и существующие browser account/payment flows. Однотонная геометрия/zoom/globe night и adaptive icon.

Официальное ядро сохранено: XDrive/MASQUE full JSON и проверки параметров, отдельное согласие для OAuth. Добавлены транспортный стенд и Android instrumentation job. Убраны лишний SOCKS listener и debug log, ограничены QR/metrics/update metadata. Приёмка ограничена TEST_REPORT; native account API/public releases/physical tests не объявляются готовыми.
